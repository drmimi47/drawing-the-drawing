MASTER PLAN — "Dynamic Trace Paper"
================================================================================
A sketch-to-plan ideation tool for architects and urban designers working on
early-stage site layout, massing, and zoning alternatives. Designers draw rough
freehand geometry, clean it into legible linework, lock/approve what works, and
(later) generate alternatives under those constraints. Output is purely vector,
returning into a clean structural graph — never a flattened raster.

Mental model:  SKETCH → DECREE INTENT (locks + intent fields) → RESOLVE.
  - "Clean up" resolves geometry toward geometric intent (primitives / morphology).
  - "Generate" (Phase 2, LLM) resolves toward programmatic intent (the intent fields).
  Both are gated by the same spatial fields. Locks freeze; intent pins steer.

Derived from plan_final_v4. This document is the build-ready version: same vision,
but sequenced so each piece ships and verifies on its own, with the LLM deferred.


HOW THIS PLAN DIFFERS FROM v4 (read first)
------------------------------------------
1. LLM IS DEFERRED to Phase 2. Nothing in Phase 1 calls a network model. The whole
   Generate pipeline (serialization, validation, accept/reject preview) is built and
   tested in Phase 1 against a DETERMINISTIC STUB generator; only the final swap to
   the Anthropic API is Phase 2. This keeps momentum and avoids LLM rabbit-holes.
2. The two heavy clusters (Hybrid Fields, Generate) are DECOMPOSED into small steps,
   each compileable and verifiable, so we don't overcomplicate or rush.
3. Normalize's "Urban Morphology Engine" is staged as incremental additions on top of
   the existing primitive fitter — not a big-bang rewrite.
4. The v4 data model (isContext, LockPolygon, IntentPin) is adopted now, because the
   field work depends on it.

DECISION TO CONFIRM: v4's status line says circle/triangle recognition was omitted,
but the current code HAS line/H-V/circle/triangle/rectangle fitting (unit-tested).
Recommendation: keep them as general primitives but DEPRIORITIZE; let urban
morphology (corridors / convex blocks / greenways) lead. They can be gated off in the
"Clean up" options if they prove noisy for plan drawing. (No code deletion required.)


WORKFLOW (guided, non-modal loop)
---------------------------------
1. SKETCH       Freehand draw rough geometry (or trace an underlay).
2. NORMALIZE    "Clean up" morphs rough strokes into clean primitives + urban
                morphology (lines, H-V, corridors, convex blocks, greenways).
                Preview → accept/reject.
3. LOCK/INTENT  Lasso regions to freeze (feathered falloff); drop Intent Pins to tag
                programmatic intent. Locks gate normalize + generate; pins steer generate.
4. GENERATE     (PHASE 2) Vector inpainting: locked = fixed anchors, feathered = bend/
                attach zone, open = free; steered by intent pins. Reviewable vector layer.

Loop: sketch ⇄ normalize ⇄ lock/intent ⇄ generate, in any order.


DESIGN PRINCIPLES (non-negotiable)
----------------------------------
- Deliberate, never ambient: transforms run on explicit command / chosen region —
  never as a side effect of panning. (The old pan-driven morph is retired.)
- Transforms only touch UNLOCKED geometry.
- Non-destructive: every action reversible; version history is core.
- Predictable field view: always show what is frozen, feathered, or targeted.
- Editable end-to-end: generation returns vectors into the graph, never raster.
- Context vs. sketch: imported background geometry (GIS / site boundaries / drawings)
  is read-only (isContext) and acts as permanent immutable anchors.
- Vector-control toggle: a switch puts strokes into editable-vector mode (move/reshape
  control points), distinct from freehand draw.


POSITIONING (honest scope)
--------------------------
Early ideation: napkin sketch → legible diagram → alternatives. Opposite end of the
pipeline from Bluebeam Revu (precision markup/takeoff on finished PDFs); this AIDS that
flow as an ideation front-end that hands off to Bluebeam / CAD. Interop matters (import
PDF/image/GIS underlay to trace; export SVG/PDF/PNG, DXF later). Real-world scale
("set scale by reference") is deferred.


CORE DATA MODEL (adopt now)
---------------------------
Editable model = planar graph of vertices + edges (PSLG), the source of truth — not a
Bezier/spline truth (curves are an optional layer that tessellates down). Render = cache.

  RawSample   { x, y, pressure, t }                       retained per stroke
  Vertex      { id, x, y, isContext: boolean }            shared at intersections; immutable bg flag
  PathPoint   { v: vertexId, w }                          per-stroke half-width
  Stroke      { id, color, path: PathPoint[], raw? }      ordered path through vertices
  Edge        { id, strokeId, v0, v1 }                    derived
  Graph       { vertices: Record<id,Vertex>, strokes: Stroke[] }
  LockPolygon { id, points: {x,y}[], featherRadius }      hard + feathered geometric lock
  IntentPin   { id, x, y, radius, intentType, value }     spatial prompt tag (steers generate)
  Snapshot    { timestamp, graph }                        version history

Render (Tier 3): centripetal Catmull-Rom resample per path → variable-width ribbon with
round caps; rebuilt from the graph. Crossing strokes insert ONE shared vertex into both.

Tool enum:  'DRAW' | 'ERASE' | 'PAN' | 'LASSO_LOCK' | 'INTENT_PIN'
Stage enum: 'SKETCH' | 'NORMALIZE' | 'LOCK_INTENT' | 'GENERATE'

================================================================================
PHASE 1 — NON-LLM FOUNDATION  (build this now, in order)
================================================================================

CLUSTER G — Workflow orchestration + explicit "Clean up"
  G1 [ ] Stage state ('SKETCH'|'NORMALIZE'|'LOCK_INTENT'|'GENERATE') + top-center stage
         indicator surfacing the current stage's primary action. Non-modal.
  G2 [ ] Selection: marquee + lasso to select a set of strokes (selection state in store).
  G3 [ ] "Clean up" command on UNLOCKED geometry (selection-scoped OR global), with a
         strength slider, rendered as a ghost PREVIEW; Accept commits, Cancel restores.
         Snapshot to history before commit. (Reuses existing normalizeStroke.)
  G4 [ ] Retire ambient pan-morph: geometry must not change on pan/zoom. Keep the
         observer/boundary only if reused later by an optional "cleanup lens".
  G5 [ ] (After G1–G4) Vector-control toggle: editable-vector mode to drag vertices.
  * Verify: pan never mutates geometry; Clean up previews and commits only on Accept;
    Cancel restores exactly; a selection limits the effect to chosen strokes.

CLUSTER H — Hybrid Fields  (decomposed — do not bundle)
  H1 [ ] LockPolygon data structure + LASSO_LOCK tool: draw/close a polygon; store it.
  H2 [ ] Hard lock: point-in-polygon → influence 1.0 inside. Wire into Clean up (skip
         influence-1 vertices). Verify locked strokes are untouched. (No feather yet.)
  H3 [ ] Feathered falloff: analytical distance-to-polygon field; influence slopes 1.0→0.0
         across featherRadius. Clean-up effect scales by (1 - influence).
  H4 [ ] Lock-field shader: crisp polygon border + outward neon glow over the feather zone.
  H5 [ ] IntentPin tool + data: place pins; edit properties (density / pedestrian flow /
         SQF priority / land-use). Pins do NOT freeze geometry.
  H6 [ ] IntentPin metaball field + color-coded shader (overlapping land-use profiles).
  * Verify: Clean up fully bypasses influence-1 vertices and scales by falloff elsewhere;
    lock + intent fields render clearly at 60 FPS. (Pins are data+visual only until Phase 2.)

CLUSTER J — Version history & non-destructive iteration
  [ ] Snapshot graph before each transform (cap ~200); undo/redo across transforms;
      restore-version affordance; optional trace-paper overlay of stacked snapshots.
  * Verify: any transform reverts; restoring a version reproduces it exactly.

CLUSTER K — Interop & handoff
  [ ] Import PDF/image/GIS as a dimmed read-only underlay; tag imported vertices isContext=true.
  [ ] Export SVG + PDF + PNG (DXF later).
  [ ] (Deferred) set-scale-by-reference.
  * Verify: trace an imported plan and export vectors that open cleanly in Bluebeam / CAD.

CLUSTER N — Normalize: Urban Morphology Engine  (incremental; each step standalone)
  N1 [ ] Parallel-corridor detection: near-parallel dual paths (or a single path tagged
         as a corridor) → clean parallel ribbon centerline.
  N2 [ ] Convex polygon: generalize rectangle fitting to clean convex N-gon parcels/blocks.
  N3 [ ] Meandering polyline: open flowing contour → smoothed greenway (NOT snapped to a
         rigid primitive).
  N4 [ ] Offset Assist: expand a normalized centerline into a parallel road/corridor ribbon
         at a chosen width.
  N5 [ ] Draw-Assist / hold-to-snap: pause at stroke end to snap to line/corridor primitive.
  * Verify (per step): each morphology type has a unit test (rough input → expected clean
    output) mirroring the existing normalize tests; no regression in line/H-V/rectangle.


================================================================================
PHASE 2 — LLM GENERATION  (deferred; build last)
================================================================================
Pre-work P1–P3 is non-LLM and safe to build during Phase 1 if convenient; the actual
model call (I) is the only true LLM dependency.

  P1 [ ] Serialization (pure fn, unit-tested, NO network): split the graph into
         LOCKED (influence 1.0 / isContext), TRANSITION (0<influence<1, the feather zone),
         and OPEN (influence 0); attach the Intent Pin spatial matrix (params → coords).
  P2 [ ] Graph Validation Guard (pure fn, unit-tested): strip self-intersections,
         overlapping/collinear paths, and degenerate topologies from a candidate segment set.
  P3 [ ] Reviewable-layer plumbing with a STUB generator: a deterministic local
         "completer" (e.g. extend dangling segments, close near-enclosures) feeds the
         accept/reject preview. Proves the full pipeline without any model.

  CLUSTER I — Real Generate (LLM)
  I1 [ ] api/generate.ts: Vercel Edge Function proxying the Anthropic API (key server-side).
  I2 [ ] System prompt: keep locked geometry exact; attach within the feather zone; lay out
         programmatic additions in open regions honoring nearby intent params.
  I3 [ ] Swap the P3 stub for the live call; run returned vectors through the P2 guard;
         animate the reviewable layer in; accept merges, reject discards; snapshot before merge.
  * Verify: Generate respects locked boundaries, anchors smoothly in the feather zone,
    builds features matching intent tags, and never breaks planar-graph topology.


CLUSTER L — Polish, hotkeys, deploy  (final)
  [ ] Hotkeys (tools, stage action, undo/redo); tablet pressure; perf guard for large
      graphs (avoid full re-tessellation each transform frame); Vercel prod deploy.
  * Verify: full sketch → clean up → lock/intent → (generate) → export loop at 60 FPS; URL live.


BUILD ORDER (one line)
----------------------
G → H → (J, K, N can interleave) → P1–P3 → I → L.
Next up: CLUSTER G. Do NOT start any LLM/network work until Phase 1 + P1–P3 are solid.
