METABALL SKETCH — Master Plan
================================================================================
A sketch-to-plan ideation tool for architects. Designer draws rough geometry,
normalizes it, locks regions + drops intent pins, then an LLM generates vector
alternatives under those spatial constraints. Output is always PSLG vectors.

Mental model:  SKETCH → LOCK/INTENT → GENERATE
  "Clean up" resolves geometry toward geometric intent (primitives / morphology).
  "Generate" (Phase 2) resolves toward programmatic intent (the intent fields).
  Locks freeze geometry; intent pins steer generation.

================================================================================
PHASE 2 — LLM GENERATE (next)
================================================================================

The serialization infrastructure is already built. What remains:

  1. api/generate.ts — Vercel Edge Function proxying Anthropic API (server-side
     key). Receives: PSLG graph + lockInfluence field + intentMix spatial matrix.

  2. System prompt — encodes:
       LOCKED (influence 1.0)   = fixed anchors, do not move
       TRANSITION (0 < inf < 1) = feather zone, bend/attach here
       OPEN (influence 0)       = free to generate
       intentMix per vertex/region = programmatic intent (density, pedestrian, etc.)

  3. Parametric return format — Claude returns structured parameters / layout
     rules, NOT raw coordinates. A local TypeScript layout engine interprets
     these rules and writes mathematically precise vertices back into the PSLG
     (avoids token-limit blowout and coordinate hallucination).

  4. Reviewable layer — vector diff displayed before committing:
       Accept → merges into graph + snapshot
       Reject → discards; graph unchanged

  5. Generate tab activation — swap the ribbon placeholder for the live UI.

NOTE: The serializer (io/intentSerialization.ts) already produces the correct
intentMix payload. lockInfluenceAt() already partitions vertices by zone.
metersPerWorldUnit already provides real-world scale context. Phase 2 is
primarily the Edge Function + prompt engineering + the layout interpreter.
