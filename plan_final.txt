BLINDSPOT — IMPLEMENTATION PLAN
================================================================================
A sketch-to-plan ideation tool: designers draw rough freehand geometry, clean it
into legible linework, lock what works, and generate new ideas under those
constraints. Optimized for step-by-step development using generative code agents.


DESIGNER WORKFLOW (the core sequence)
-------------------------------------
The three former "modes" are now stages of one guided, non-modal loop. The user
can move freely between them; the UI suggests the next step but never forces it.

  1. SKETCH      Freehand draw rough geometry (done — Clusters B–D).
  2. NORMALIZE   Explicit "Clean up" command morphs rough strokes into clean
                 primitives (line / H-V / circle / triangle / rectangle). Preview,
                 then accept or reject. Re-sketch and re-normalize as often as wanted.
  3. LOCK        Mark regions you're happy with as protected. Locks freeze geometry
                 against BOTH further normalization and generation.
  4. GENERATE    "Hallucination": send the drawing to an LLM with locked geometry as
                 fixed anchors and unlocked area as the region to extend/complete —
                 vector inpainting, a controllable alternative to a diffusion model.
                 Returned geometry arrives as a reviewable layer (accept / reject).

  Loop: sketch ⇄ normalize ⇄ lock ⇄ generate, in any order, repeatedly.

DESIGN PRINCIPLES (non-negotiable for professional use)
  - Deliberate, not ambient: transforms run on command, never as a side effect of
    panning. (The original viewport-driven auto-mutation survives only as an OPTIONAL
    "ambient" toggle, off by default.)
  - Non-destructive: every normalize/generate is preview → accept/reject, fully
    undoable, and snapshotted to version history before it runs.
  - Predictable locking: the user can always see exactly what is protected.
  - Editable end to end: generation returns vectors into the planar graph, never
    raster — so any AI output remains hand-editable.


POSITIONING & PRACTICAL INTEGRATION (be honest about scope)
-----------------------------------------------------------
Target: the EARLY ideation phase of planning — the napkin sketch becoming a legible
diagram and a springboard for alternatives. This is the opposite end of the pipeline
from Bluebeam Revu, which is precision markup, measurement, and takeoff on finished
PDFs. So this tool AIDS that workflow rather than replacing it: it is the ideation
front-end that hands off to Bluebeam / CAD.

Implications that shape the plan:
  - Interop is a feature, not polish: import a PDF/image as a dimmed underlay to
    sketch over (mirrors tracing in Bluebeam); export SVG / PDF / PNG (DXF later) so
    output flows downstream. (Cluster K.)
  - Real-world scale and dimensions are deferred but anticipated: a PDF underlay +
    "set scale by reference" is the highest-leverage future addition.
  - Rationalism mode is OUT OF SCOPE for now (removed from the sequence).

CORE DATA MODEL  (layered — editable graph is the source of truth)
------------------------------------------------------------------
Architecture decision: the editable model is a planar graph of vertices + edges
(a PSLG), NOT a Bezier/spline source of truth. Reasons: every planned feature —
Normalization (snap edge angles), Rationalism (drift vertices to grid), Locking
(per-vertex influence), Lineage (vertex/edge snapshots), and especially
Hallucination (LLM edits a JSON segment list) — operates on segments and shared
vertices. A curve-as-truth model would force a lossy tessellate→operate→re-fit
round-trip on every mutation and make AI edits topologically fragile. Curves stay
an OPTIONAL layer (per-vertex tangents / edge curve descriptors) that always
tessellates down to the polyline graph; this preserves a path to arcs/constraints
later without blocking the segment-based features now.

Three decoupled tiers:
  Tier 1 — Input        Raw pointer samples retained per stroke (re-fit / analysis)
                        RawSample { x, y, pressure, t }
  Tier 2 — Edit model   Planar graph; the SOURCE OF TRUTH for editing/mutations/AI
                        Vertex    { id, x, y }            (position; shared at intersections)
                        PathPoint { v: vertexId, w }      (per-stroke half-width at that vertex)
                        Stroke    { id, color, path: PathPoint[], raw?: RawSample[] }
                        Edge      { id, strokeId, v0, v1 } (derived: consecutive path vertices)
                        Graph     { vertices: Record<id,Vertex>, strokes: Stroke[] }
                        (future-reserved on Vertex: tangentIn/Out; on Edge: curve descriptor)
  Tier 3 — Render       Triangle ribbon, a DERIVED CACHE rebuilt from Tier 2:
                        centripetal Catmull-Rom resample of the path → smooth
                        centerline → variable-width ribbon with round caps.

Pin      { id, x, y, radius }            (Cluster H)
Snapshot { timestamp, graph: Graph }     (Cluster I)

Shared vertices give topology: when stroke B crosses stroke A, one Vertex is
inserted into BOTH paths at the crossing, so the strokes meet at a real node that
mutations can act on. Width lives on the PathPoint (per stroke), position on the
Vertex (shared). Smoothness is a Tier 1/3 concern (retain raw, resample, round
caps) — independent of the editable model, which fixes the post-finalize
faceting caused by raw RDP decimation.

Tool state enum:  'DRAW' | 'ERASE' | 'PAN' | 'LOCK'
Stage enum:       'SKETCH' | 'NORMALIZE' | 'LOCK' | 'GENERATE'


TRANSFORMS (implementation detail)
----------------------------------
NORMALIZE — IMPLEMENTED (primitive fitting, per stroke)
  - Classifies a whole stroke and fits a cleaner geometric primitive:
      open stroke            → best-fit straight line (PCA); snaps to exact H/V within 8°
      closed + round + dense → fitted circle (Kåsa algebraic fit)
      closed, 3 corners      → clean triangle
      closed, 4 corners      → fitted rectangle (orientation from corner edges, right angles)
      other closed           → left alone (ellipse / general polygon are future work)
  - Corners found via adaptive RDP around the loop; points morph along the cleaned
    edges by arc-length so corners snap to corners and edges straighten.
  - Morph is parameterized by a strength m ∈ [0,1] (lerp original → primitive, eased).
  - INVOCATION (reworked in Cluster G): an explicit "Clean up" command runs it on all
    UNLOCKED strokes with a user strength control, as a preview the user accepts or
    rejects. Locked geometry is skipped. It is no longer triggered by panning.

AMBIENT MODE — OPTIONAL (the original BLINDSPOT mechanic, off by default)
  - Viewport observer (built in Cluster E) tracks per-edge time-outside the observation
    boundary; while a stroke is unobserved it morphs toward its primitive by
    clamp(timeOutside / DECAY_MAX_MS, 0, 1). Re-entry freezes it.
  - Retained as a toggle for the conceptual/demo experience; the deliberate "Clean up"
    command is the default, professional path.

LOCK — gates BOTH normalize and generate
  - lockInfluence per vertex (0–1); effectiveStrength = m * (1 - lockInfluence)
  - At influence 1 a vertex is frozen (skipped by normalize and treated as a fixed
    anchor by generate). Details in LOCKING MECHANISM below.

GENERATE ("Hallucination") — constraint-guided vector completion (LLM)
  - Serialize the graph split into LOCKED (fixed anchors / the "mask") and UNLOCKED
    (the region to extend or complete) → JSON segment list.
  - POST to the Anthropic API (claude-sonnet-4-6 via a Vercel Edge Function; key stays
    server-side) with a spatial-completion prompt: keep locked geometry exactly, extend
    short segments toward adjacencies, close implied enclosures, propose plausible
    additions in the unlocked area.
  - Parse returned segments → add as a NEW reviewable layer (accept / reject), animated
    in over 1–2s. Output is vectors merged into the planar graph, so it stays editable.
  - This is the "controlled diffusion" idea as inpainting: locks are the mask; a
    strength/temperature control governs how far it deviates.


LOCKING MECHANISM
-----------------
Lock = "approve / protect": locked geometry is skipped by Clean up and held fixed by
Generate (it is the inpainting mask).
- Metaball pins (signature): shift+click when tool is 'LOCK'
    influence_i = clamp(1 - dist(v, pin)² / pin.radius², 0, 1)
    multiple pins: totalInfluence = clamp(sum of all influences, 0, 1)
    visualized as soft glowing rings (influence.frag shader, smooth radial falloff)
- Region lock (predictable alternative): drag a rectangle / lasso to mark vertices as
    fully locked (influence = 1). Pros want to see exactly what is protected.
- effectiveStrength = m * (1 - totalInfluence) feeds both normalize and generate.


VERSION HISTORY (formerly "evolutionary lineage")
-------------------------------------------------
The mechanism that makes the destructive steps safe — reframed from art reveal to
trustworthy versioning.
- Snapshot the whole graph BEFORE each transform (Clean up / Generate / Ambient run).
- Browse and restore any prior version; undo/redo across transforms.
- "Trace-paper" overlay view (optional, the original lineage aesthetic): render all
  snapshots stacked with opacity = lerp(0.05, 1.0, index/total) to see the evolution.
- "Export" captures the current state (raster PNG now; SVG/PDF vector in Cluster K).

OPEN QUESTIONS / DECISIONS TO REVISIT
--------------------------------------
- Intersection detection: brute-force O(n²) is fine for sketch scale; upgrade to
  Bentley-Ottmann sweep-line if performance degrades on large drawings
- Dot-grid implementation: shader-based (most performant) vs. instanced mesh tiles —
  decide during Cluster A based on zoom-scaling behavior
- Wacom full SDK (pressure curves, tilt): requires browser plugin; treat as an
  enhancement over the standard PointerEvent.pressure path already in Cluster B
- History memory cap of ~200 snapshots: revisit if it limits iteration depth
- RESOLVED: deliberate "Clean up" is the default; viewport auto-mutation is an optional
  ambient toggle (off by default) — professional tools must not change geometry on pan
- RESOLVED: "controlled diffusion" = LLM vector inpainting (locks = mask), not raster
  generation — keeps output editable in the planar graph
- Positioning: ideation front-end that feeds Bluebeam/CAD, not a markup/takeoff
  replacement; interop (Cluster K) is what makes it fit a real workflow
- Lock UX: metaball pins (signature) vs. rectangle/lasso region lock (predictable) —
  ship both; watch which designers actually reach for
- Generate trust: always accept/reject + snapshot; consider showing the LLM's additions
  in a distinct color until accepted
- Real-world scale/dimensions deferred; PDF underlay + "set scale by reference" is the
  highest-value next step toward genuine planning use
