drawing project — IMPLEMENTATION PLAN
================================================================================
A sketch-to-plan ideation tool. Designers draw rough freehand geometry, clean it
into legible linework, lock/approve what works, and generate new ideas under those
constraints. More fine-grained control than a diffusion render model: the designer
decides exactly what gets resolved and what gets generated.

One mental model: SKETCH → place INTENT (locks/fields) → RESOLVE. "Clean up" and
"Generate" are the same idea at two strengths — resolve geometry toward intent —
and the lock field is the single dial for how much resolving is allowed where.


WORKFLOW (a guided but non-modal loop)
--------------------------------------
The user can move between stages freely; the UI just suggests this order.

  1. SKETCH      Freehand draw rough geometry. (Done. Polylines/shapes later.)
  2. NORMALIZE   "Clean up" morphs rough strokes into clean primitives
                 (line / H-V / circle / triangle / rectangle). Preview → accept/reject.
  3. LOCK        Mark regions you like as protected fields. Locks gate BOTH
                 normalization and generation. (Pins can also carry design intent.)
  4. GENERATE    Send the drawing to an LLM with locked geometry as fixed anchors and
                 the unlocked area as the region to extend/complete (vector inpainting).
                 Parametrized: degree of generation + which protocol to prioritize
                 (SQF maximization, circulation, daylight, ...). Returns a reviewable
                 vector layer (accept/reject) that stays hand-editable.

  Loop: sketch ⇄ normalize ⇄ lock ⇄ generate, in any order, repeatedly.


DESIGN PRINCIPLES (non-negotiable)
----------------------------------
- Deliberate, never ambient: transforms run on explicit command or over a chosen
  selection/region — never as a side effect of panning.
- Transforms only ever touch UNLOCKED geometry.
- Vector-control toggle: a switch puts lines/shapes into an editable-vector mode so
  they can be transformed (move/reshape control points), distinct from freehand draw.
- Non-destructive: every action is reversible; version history is core.
- Predictable locking: the user can always see exactly what is protected.
- Editable end-to-end: generation returns vectors into the planar graph, never raster.


POSITIONING (honest scope)
--------------------------
Targets the EARLY ideation phase — napkin sketch → legible diagram → alternatives.
The opposite end of the pipeline from Bluebeam Revu (precision markup/takeoff on
finished PDFs). This AIDS that workflow: an ideation front-end that hands off to
Bluebeam / CAD. So interop matters — import a PDF/image underlay to trace; export
SVG/PDF/PNG (DXF later). Real-world scale ("set scale by reference") is deferred.


NORMALIZE — how/when it runs (the reworked trigger model)
---------------------------------------------------------
Primitive fitting is IMPLEMENTED (per stroke): open → best-fit line (snaps to exact
H/V within 8°); closed+round+dense → circle (Kåsa); closed 3 corners → triangle;
closed 4 corners → rectangle; else left alone. Corners via adaptive RDP; points
morph along the cleaned edges by arc-length. Morph strength m ∈ [0,1] (eased lerp
original → primitive). Locked vertices are skipped.

The old "mutates when off-screen" mechanic is replaced by explicit triggers:
  - SELECTION-SCOPED (core): marquee/lasso strokes, then "Clean up" applies only to them.
  - GLOBAL BUTTON + STRENGTH (core): clean all unlocked geometry at a chosen strength,
    shown as a ghost preview, accept/reject.
  - CLEANLINESS SLIDER (signature): one global 0–100% tidiness knob morphs all unlocked
    geometry live; the designer dials in how resolved the drawing is.
  - CLEANUP LENS (signature): a deliberate draggable frame/brush; sweep it over rough
    lines to clean what's underneath. (Repurposes the old observation frame as a tool.)
  - DRAW-ASSIST (opt-in): hold at the end of a stroke to snap it to its primitive.
Recommended build order: selection + global button + strength + preview first; then the
cleanliness slider and lens as the signature interactions.


LOCKING AS A FIELD (the signature mechanic)
-------------------------------------------
A lock is a continuous influence field, not a binary flag — that is the differentiator.
- Metaball pins: shift+click in LOCK tool; influence_i = clamp(1 - d²/r², 0, 1);
  multiple pins sum then clamp; soft glowing rings (influence.frag).
- Region lock: drag a rectangle/lasso to fully lock enclosed vertices (influence = 1).
- effectiveStrength = m * (1 - totalInfluence) feeds BOTH normalize and generate.

Where this goes (roadmap, builds on the same field):
- Soft generative mask: graded influence = how much freedom Generate has per region
  (core frozen → falloff nudge-only → outside free). Soft-edged inpainting.
- Signed fields: positive pins protect/keep; negative pins "open up" a region and
  invite generation. The designer sculpts where ideas grow vs. stay fixed.
- Intent pins: a pin carries a tag (circulation / daylight / SQF-max / private) and its
  field paints that intent locally; Generate reads the field to prioritize that protocol
  in that area. Spatial prompting by placing fields on the canvas.
- Certainty heatmap: render the combined field as a "decided vs. exploratory" map —
  doubles as a review/communication artifact.


GENERATE — constraint-guided vector completion (LLM)
----------------------------------------------------
- Serialize the graph split into LOCKED (fixed anchors / mask) and UNLOCKED (region to
  extend) → JSON segment list (plus any intent-field tags).
- POST to the Anthropic API (claude-sonnet-4-6) via a Vercel Edge Function (key stays
  server-side). Prompt: keep locked geometry exactly; extend dangling segments, close
  implied enclosures, propose additions in the unlocked area; honor the prioritized
  protocol and the degree-of-generation parameter.
- Parse returned segments → add as a NEW reviewable layer (accept/reject), animated in.
  On accept they become ordinary editable strokes in the graph. Graceful API failure.


CORE DATA MODEL (essentials)
----------------------------
Editable model = a planar graph of vertices + edges (PSLG), the source of truth — NOT a
Bezier/spline truth (segments keep normalize/generate/topology lossless; curves stay an
optional layer that tessellates down). Rendering is a derived cache.

  RawSample { x, y, pressure, t }                  retained per stroke (Tier 1)
  Vertex    { id, x, y }                            shared at intersections
  PathPoint { v: vertexId, w }                      per-stroke half-width
  Stroke    { id, color, path: PathPoint[], raw? }  ordered path through vertices
  Edge      { id, strokeId, v0, v1 }                derived (consecutive path vertices)
  Graph     { vertices: Record<id,Vertex>, strokes: Stroke[] }
  Pin       { id, x, y, radius, intent? }           lock field source
  Snapshot  { timestamp, graph }                    version history

Render (Tier 3): centripetal Catmull-Rom resample of each path → variable-width ribbon
with round caps; rebuilt from the graph. Crossing strokes insert ONE shared vertex into
both paths.

Tool enum:  'DRAW' | 'ERASE' | 'PAN' | 'LOCK'
Stage enum: 'SKETCH' | 'NORMALIZE' | 'LOCK' | 'GENERATE'
